## 5. Backtest Loop (`run_backtest`)

Replicate S8002 strategy logic exactly (consistent with `strategyS8002BBV1.run_backtest` but enriched for trade record + stats):

- Config: `initial_capital = 100000`, `position_size = strategyS8002BBV1.position_size` (=110), `commission = 0.0` (strategy default; total commission cost = 0 in stats — but compute & expose a commission field for completeness). Commission model: $0.005/share, min $1 (same as S8004) — used only for reporting; strategy itself sets `commission=0.0`. **Choose one.** Recommend: honor strategy `commission=0.0` → Total Commission Cost = 0.00 (no cost applied). Keep a code comment.
- Per-bar iteration `i` over the enriched df:
  - Exits checked before entries on the same bar.
  - **Long exits** (when `position==1`):
    - ATR stop: if `Low[i] <= stop_price` → exit at `stop_price`.
    - 5-bar exit: if `i - entry_bar_index >= hold_bars (5)` → exit at `Open[i]`.
    - Force close at 15:55 (`index[i].time() == 15:55`) → exit at `Open[i]`.
  - **Short exits** (when `position==-1`):
    - ATR stop: if `High[i] >= stop_price` → exit at `stop_price`.
    - 5-bar / 15:55 force close same as long.
  - **Entries** (only when flat, `in_window = 09:30 <= t <= 14:55`):
    - `buy_signal[i]` True → entry at `Open[i]`; `stop_price = Open[i] - prev_atr(7)[i-1]*2.5`; long.
    - `short_signal[i]` True → entry at `Open[i]`; `stop_price = Open[i] + prev_atr(7)[i-1]*2.5`; short.
  - Equity tracked each bar: `capital + unrealized` (unrealized uses `Close[i]`).
- Per closed trade record fields:
  - `symbol` (from Symbol col, else 'NVDA'), `type` ('Long'/'Short'), `entry_time`, `entry_price`, `exit_time`, `exit_price`, `pnl`, `shares`, `position_value = entry_price*shares`, `mae`, `mfe`, `bars_held`.
  - MAE/MFE (long): `mae=(min Low[entry..exit]-entry)*shares`; `mfe=(max High[entry..exit]-entry)*shares`.
  - MAE/MFE (short): `mae=(entry-max High)*shares`; `mfe=(entry-min Low)*shares`.
- Compute all statistics (see §6).

## 6. Statistics (HTML)

Compute and render every required metric:
Initial Capital, End Capital, Net Profit, Net Profit %, Exposure %, Annual Return %, Total Commission Cost, Number of trades, Number of Long trades, Number of Short trades, Number of wins, Number of wins %, Total win amount, Number of loss, Number of loss %, Total loss amount, Average Profit/Loss, Average Profit/Loss %, Maximum trade drawdown, Maximum system drawdown, CAR/MaxDD, Profit Factor, Sharpe Ratio (rf=3% annual), Ulcer Index, K-Ratio.

Metric formulas (follow S8004 reference):
- Exposure % = (bars in position / total bars) * 100.
- Annual Return % = `((end/init)^(1/years)-1)*100`, `years = days/365.25`.
- Sharpe: per-bar excess returns vs `rf/bars_per_year`, annualized by `sqrt(bars_per_year)`.
- Ulcer Index: `sqrt(mean(dd_pct^2))` on equity vs cummax.
- CAR/MaxDD = `annual_return / max_system_drawdown_pct`.
- K-Ratio = `(sum(returns)/std(returns))/sqrt(n)`.
- Max trade drawdown = min single-trade `pnl`.
- Max system drawdown = peak-to-trough % on equity curve.

HTML: reuse S8004 template — Chart.js equity line chart + 3 stat grids (Performance / Trade / Risk). Title "Backtest Report - S8002 BB V1 NVDA".
