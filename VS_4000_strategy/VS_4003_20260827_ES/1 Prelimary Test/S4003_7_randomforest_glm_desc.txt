1. WHAT THIS PROGRAM DOES
-------------------------
Walk-forward parameter test of the ES intraday strategy (strategyIRB1000_V1
logic, class strategyS4003V1) with a lookahead-free out-of-sample day gate.

Analysis period : 2025-08-01 .. 2026-09-11 (data loaded from MariaDB
                  ticker1Min; stn1/sln1 daily stops stay disabled)
Pipeline        :
  Phase 1  calibration grid (first 28 days of the period, before any
           walk-forward day): full (w1, n1, e1) grid; the 2 parameters with
           the widest win-rate spread are chosen for walk-forward, the 3rd
           is fixed at the calibration backtest best.
  Phase 2  gate selection: a mini walk-forward over the last 5 calibration
           days picks an IS win-rate threshold (gate). A walk-forward day is
           only traded when its in-sample-selected configuration shows
           IS win rate >= gate AND IS net > 0. wr_min = 0.0 is the
           net>0-only baseline. Real OOS data is never touched.
  Phase 3  walk-forward: rolling in-sample 14 days -> out-of-sample 1 day,
           per OOS day the best (w1, n1) of the calibration-chosen pair is
           selected on the IS window ending the day before (key: enough
           trades, win rate, net), then the OOS day is traded only if the
           gate passes. Skipped days produce no trades.
Target         : out-of-sample win rate >= 65% (reported honestly as
                 PASS/MISS).
Run            : python S4003_7_randomforest_glm.py [--ticker ES]

4. TEST TYPE
------------
WALK-FORWARD TEST (not a plain backtest):
  - calibration grid + gate selection on a 28-day window (lookahead-free)
  - rolling in-sample 14 days -> out-of-sample 1 day, over every trading day
    after the calibration window
  - per-OOS-day gate derived from calibration only

5. PARAMETERS REQUIRED
----------------------
  Command line : --ticker ES (default)
  Internal     : ANALYSIS_START = 2025-08-01, ANALYSIS_END = 2026-09-11 23:59:59
                 CALIB_DAYS = 28, IS_DAYS = 14, GATE_SELECT_DAYS = 5
                 GATE_WR_GRID = (0, 40, 45, 50, 55, 60) % IS win rate
                 GATE_MIN_TAKEN = 3, WIN_RATE_TARGET = 65%
                 MIN_IS_TRADES (from S4003_5), EXIT_COST = 14.50 (from S4003_3)
  Strategy     : w1 (profit multiplier), n1 (stop bars), e1 (entry offset)
                 grids W1_GRID / N1_GRID / E1_GRID (from S4003_3); stn1/sln1
                 daily stops always None (disabled)

6. FUNCTIONS IN THIS PY FILE
----------------------------
  class S4003V7WalkForward
    _load()           load 1-min bars from MariaDB, prepare signals

                      calibration days

                      mini-OOS days only
    walk_forward()    phase 2: rolling IS 14d -> OOS 1d with the day gate;
                      per-day rows, trades, equity segments

                      write_outputs -> _restore_params (S4003_3)
