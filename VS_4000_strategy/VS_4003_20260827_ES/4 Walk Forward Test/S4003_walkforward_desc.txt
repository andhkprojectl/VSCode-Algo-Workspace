1. WHAT THIS PROGRAM DOES
-------------------------
Walk-forward test for the ES intraday strategy (class strategyS4003,
ported from 1 Prelimary Test\S4003_7_randomforest_glm.py). All parameters
come from config.yaml section "WalkForward Test" (signal/account parameters
from section "Strategy"); data from MariaDB table ticker1Min
(analysisStart 2025-08-01 .. analysisEnd 2026-09-11, 424,857 bars loaded,
349 trading days).

Pipeline:
  Phase 1  calibration grid (first 28 days, before any walk-forward day):
           full (w1, n1, e1) grid; the 2 parameters with the widest win-rate
           spread are chosen for walk-forward, the 3rd (e1) is fixed at the
           calibration backtest best.
  Gate     threshold selection on the last 5 calibration days only (mini
           walk-forward, lookahead-free): a day is taken only when its
           in-sample-selected configuration shows IS win rate >= threshold
           AND IS net > 0. wr_min = 0.0 is the net>0-only baseline.
  Phase 2  rolling walk-forward: in-sample 14 days -> out-of-sample 1 day,
           stepping 1 day, over every trading day after the calibration
           window. Per OOS day the best (w1, n1) is selected on the IS
           window ending the day before (key: enough trades, win rate, net),
           then the day is traded only if the gate passes (IS win rate >=
           gate threshold AND IS net > 0). Skipped days produce no trades.
  stn1/sln1 daily stops stay unset (disabled).
Target    : out-of-sample win rate >= 65% (reported as PASS/MISS).
Run       : python S4003_walkforward.py [--ticker ES] [--config <path>]

Latest run results (both timing runs, deterministic):
  607 trades on 291 taken days (34 gated out)
  win rate 44.32% (target >= 65% -> MISS)
  net 13,813.10   Sharpe 2.38   max DD 2.56%

2. FUNCTIONS IN THE PY FILE
---------------------------
Module-level functions:

  loadWalkForwardConfig(config_path=None)
      Load and return the "WalkForward Test" section of the strategy
      folder config.yaml.
  _load_db_env()
      Load VS_0002_config\.env if present (DB credentials, repo convention).
  _db_connect()
      Open a MariaDB connection from the .env variables.
  get_db_range(ticker, table)
      Return (min, max) datetime1 of the ticker in the table.
  load_data_from_db(ticker, start_date, end_date, table)
      Read OHLCV bars into a DataFrame (DatetimeIndex, columns
      Open/High/Low/Close/Volume).
  _sharpe_from_eq(eq, rf_annual=None)
      Annualized Sharpe ratio of a bar-level equity series
      (risk-free rate from strategy config, 3% default).
  _max_dd_from_eq(eq)
      Max system drawdown (%) of a bar-level equity series.
  window_metrics(trades)
      Return dict {trades, wins, win_rate, net} for a trade list.

Class S4003WalkForward (port of S4003V7WalkForward):

  __init__(ticker, config_path)
      Read all walk-forward parameters from the config section
      (analysisStart/End, calibDays, iisDays, oosDays, oosStepDays,
      rollingWindow, gateSelectDays, gateWrGrid, gateMinTaken,
      minIsTrades, winRateTarget, lookbackBars, param1/param2/fixedParam
      grids, outputFolder); exitCost = commissionPerTrade.
  _set_params(w1, n1, e1)
      Push profit_mult / stop_period1 / entry_limit_atr_frac / commission
      onto the strategyS4003 class.
  _simulate_window(sig, start, end, w1, n1, e1, stn1, sln1)
      Run the strategy engine on [start, end] (lookbackBars bars kept
      before start for indicator warm-up, entries gated to the window).
      stn1/sln1 must be None (disabled). Returns (trades, bar-level equity).
  _load()
      Load bars from MariaDB, build signals via strategyS4003._prepare,
      classify analysis / trading / calibration days.
  _run_cfg(w1, n1, e1)
      One backtest over the calibration window, metrics dict.
  _rank_key(r)
      Static ranking key: (freq >= 0.5 and net > 0, win_rate, net).
  grid_search()
      Phase 1: calibration grid, win-rate spread per parameter, choose the
      2 walk-forward parameters, fix the 3rd at calibration best.
  _is_best_cfg(day, p1, p2, grid, fv)
      Best (w1, n1) on the IS window ending the day before; selection key
      (enough trades, win rate, net). Returns (v1, v2, is_metrics).
  select_gate()
      Select the OOS-day gate threshold on calibration mini-OOS days only
      (never touches real OOS data).
  walk_forward()
      Phase 2: per OOS day - select best (w1, n1) on the IS window ending
      the day before, apply the gate, trade the day when taken; builds
      per-day rows, trade list, equity segments.
  write_outputs(out_dir)
      Write the 6 output files + the HTML report (gate table, summary,
      per-OOS-day table, equity chart via strategyS4003._equity_chart_html).
  run()
      applyStrategyConfig -> _load -> grid_search -> select_gate ->
      walk_forward -> write_outputs -> restore original class params.

  main()
      argparse entry point (--ticker, --config).
